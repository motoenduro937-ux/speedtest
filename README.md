# speedtest

Консольный скрипт на Python для замера скорости скачивания.

## Как работает

Скрипт принимает адрес файла (например, тяжёлой картинки или тестового файла),
делает к нему 10 запросов подряд и каждый раз дожидается полного ответа.
По итогам считает среднее время одного запроса и общий объём скачанных данных,
затем выводит среднюю скорость скачивания.

## Запуск

Нужен только Python 3, сторонние библиотеки ставить не надо:

```
python speedtest.py https://speed.hetzner.de/100MB.bin
```

Аргумент — любой прямой адрес файла. Чем больше файл, тем точнее замер:
на маленьких файлах большую часть времени занимает установка соединения.

## Что печатает

- время и размер каждого из 10 запросов;
- среднее время запроса (в секундах);
- общий объём скачанных данных (в мегабайтах);
- среднюю скорость скачивания.

Единицы измерения: размер — мегабайты (1 МБ = 1024 КБ), скорость — МБ/с
(мегабайты в секунду), в скобках дополнительно выводится Мбит/с.

## Пример вывода

```
Запрос  1: 12.41 с, 100.00 МБ
Запрос  2: 11.87 с, 100.00 МБ
...
Среднее время запроса: 12.05 с
Всего скачано: 1000.00 МБ
Средняя скорость скачивания: 8.30 МБ/с (66.4 Мбит/с)
```
